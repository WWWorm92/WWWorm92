## About

I'm a **system administrator who also develops software**. My work combines day-to-day Linux and Windows administration, network design and troubleshooting, self-hosted services, VPN infrastructure and deployment automation.

I work with **MikroTik and Keenetic**, routing, VLANs, DNS, DHCP, NAT, Nginx, systemd and Docker. I also build APIs, web applications, Home Assistant integrations and native Android clients.

## Featured projects

### 💬 Pulse Messenger
**Self-hosted communication platform with a web app and native Android client.**

Private chats, rooms, file sharing, reactions, polls, admin tools, push notifications and Linux deployment automation. The Android client also supports local caching and WebRTC calling.

**Stack:** `Node.js` · `Express` · `Socket.IO` · `SQLite` · `Kotlin` · `Jetpack Compose`

[Server & Web](https://github.com/WWWorm92/ZhurMessenger) · [Android App](https://github.com/WWWorm92/ZhurMessengerApp)

### 🚗 PSADiag
**Android diagnostics and live telemetry for Peugeot vehicles via ELM327.**

Reads parameters from supported ECUs, displays live charts, handles diagnostic trouble codes and exports CSV logs. Includes background operation and a signed APK update channel. ECU coverage and compatibility vary by vehicle and firmware.

**Stack:** `Android` · `Kotlin` · `ELM327` · `CAN` · `Bluetooth`

[Project documentation](https://github.com/WWWorm92/ep6-background-logger) · [APK releases](https://github.com/WWWorm92/ep6-logger-releases/releases)

### 🏠 ETD Intercom for Home Assistant
**Unofficial integration bringing ETD intercom controls and cameras into Home Assistant.**

Door and gate controls, camera previews, live video, WHEP/WebRTC streaming and custom Lovelace cards.

**Stack:** `Python` · `Home Assistant` · `WebRTC` · `WHEP`

[Repository](https://github.com/WWWorm92/etd-intercom-home-assistant)

### 👤 Local Face Recognition
**Self-hosted face-recognition backend with a Home Assistant bridge.**

FastAPI service for processing camera images, managing known people and exposing recognition events; deployable with Docker Compose. An experimental tool, not a standalone security system.

**Stack:** `Python` · `FastAPI` · `OpenCV` · `Docker`

[Backend](https://github.com/WWWorm92/Face_Recognition_Backend) · [Home Assistant bridge](https://github.com/WWWorm92/Face_Recognition_HAIntegration)

### 🔐 AmneziaPanel
**Linux installer and management tooling for self-hosted VPN services.**

Interactive and unattended deployment on Debian/Ubuntu, with modular VPN components and supporting services.

**Stack:** `Bash` · `Linux` · `WireGuard` · `OpenVPN` · `Xray`

[Repository](https://github.com/WWWorm92/AmneziaPanel)

### 🚴 GroupRace & SwissData
**Tools for cycling events:** start lists, results, statistics, protocols and OBS graphics.

[GroupRace](https://github.com/WWWorm92/grouprace) · [SwissData](https://github.com/WWWorm92/SwissData)
