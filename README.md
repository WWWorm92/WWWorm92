## About me

I'm a **System Administrator and Developer** focused on infrastructure, networking, self-hosted services and automation.

My daily work includes **Windows and Linux, MikroTik and Keenetic, VPNs, Nginx, systemd, Python, REST APIs, Git and GitHub**.  
I also develop an Android client with **Kotlin and Jetpack Compose**.

I like building small, useful tools around real problems — especially when existing software is too limited, too cloud-dependent, or simply doesn't do what I need.
